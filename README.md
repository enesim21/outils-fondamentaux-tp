# Outils fondamentaux

- `tp/` : solutions des TP1 à TP6.
- `projet/` : comparaison de méthodes pour trouver les racines d'une fonction.

Lancer le projet : `python -m projet.main`

Installer la dépendance : `python -m pip install -r requirements.txt`

On observe le nombre d'itérations, l'erreur finale et les cas où une méthode échoue.

Une IA a aidé à écrire et organiser une partie du code. Les tests automatiques ont été exécutés ; l'analyse des résultats reste à compléter.
