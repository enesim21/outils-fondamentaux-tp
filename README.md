# Outils fondamentaux

Les solutions des TP1 à TP6 sont dans le dossier `tp/`.

Pour lancer un TP, depuis la racine du dépôt :

```bash
python -m tp.tp1
python -m tp.tp2
python -m tp.tp3
python -m tp.tp4
python -m tp.tp5
python -m tp.tp6
```

Les tests se lancent avec :

```bash
python -m tp.test_solutions
```

Avant le rendu final, ajouter le projet personnel dans un dossier `projet/` et compléter cette page avec sa description, la commande pour le lancer et les résultats à observer.

Utilisation de l'IA : une aide a été utilisée pour réorganiser le code et préparer des tests. Les fonctions et les résultats doivent être relus et comparés aux énoncés.
