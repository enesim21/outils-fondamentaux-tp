# Solveur d'equations

Le programme compare la dichotomie, la methode de Newton et une methode hybride.
Il teste plusieurs fonctions pour regarder la precision, les iterations et les cas d'echec.

Depuis la racine du depot :

    python -m pip install -r requirements.txt
    python -m projet.main
    python -m unittest projet.test_methodes -v

Les resultats sont enregistres dans `projet/resultats/`.
